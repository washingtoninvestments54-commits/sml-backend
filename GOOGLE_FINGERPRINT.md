# Google SHA-1 Fingerprint

Add this SHA-1 certificate fingerprint to the Firebase Console for the Android app:

```
BB:BE:B4:8A:CC:14:AA:7F:FC:E7:50:B0:B5:A9:70:76:A2:EB:45:21
```

## How to add:
1. Go to Firebase Console → Project Settings → Your Apps → Android app
2. Click "Add fingerprint"
3. Paste the SHA-1: `BBBEB48ACC14AA7FFCE750B0B5A97076A2EB4521`
4. Save

This fingerprint is needed for Google Sign-In to work on the production Android build.
